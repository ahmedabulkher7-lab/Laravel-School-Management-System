# School System

نظام إدارة مدرسة متكامل مبني على Laravel 12 مع دعم الأدوار والواجهات الخاصة بكل مستخدم: مشرف، معلم، وطالب.

## نبذة عن المشروع

هذا المشروع عبارة عن تطبيق ويب لإدارة العمليات التعليمية داخل المدرسة، ويغطي أساسيات الإدارة اليومية مثل:

- إدارة الطلاب والمعلمين
- إدارة المواد والمستويات الدراسية
- ربط المعلمين بالطلاب حسب المادة
- تنظيم الجداول الدراسية
- تسجيل التقدم اليومي للطلاب
- توليد التقارير الأسبوعية بصيغة PDF
- إرسال إشعارات داخلية للمستخدمين

## الميزات الرئيسية

### 1. نظام تسجيل الدخول والأدوار

المشروع يدعم ثلاث أدوار أساسية:

- Admin: المشرف العام المسؤول عن إدارة النظام بالكامل
- Teacher: المعلم الذي يسجل تقدم الطلاب ويطّلع على سجلاتهم
- Student: الطالب الذي يطّلع على أدائه وجدوله وتقاريره

### 2. إدارة الطلاب

يمكن للمشرف إدارة البيانات الأساسية للطلاب مثل:

- إضافة أو تعديل أو حذف بيانات الطالب
- ربط الطالب بالمستوى الدراسي
- حفظ بيانات ولي الأمر والهاتف
- عرض العمر بناءً على تاريخ الميلاد

### 3. إدارة المعلمين

يمكن للمشرف إدارة المعلمين وإسنادهم للمواد والمستويات الدراسية، مثل:

- إضافة وتعديل وحذف المعلمين
- ربط المعلم بالمادة التي يدرّسها
- ربط المعلم بالمستويات الدراسية
- ربط المعلم بالطلاب حسب المادة

### 4. إدارة المواد والمستويات

- إضافة المواد الدراسية
- إدارة المستويات الدراسية
- ربط المواد بالمستويات حسب احتياج النظام

### 5. تعيين المعلمين للطلاب

يوفر النظام ميزة مهمة وهي:

- ربط معلم معين بطلاب معينين في مادة محددة
- إمكانية حذف هذا الربط في أي وقت

### 6. إدارة الجداول الدراسية

يمكن للمشرف إنشاء الجداول الدراسية وتحديد:

- المستوى الدراسي
- المادة
- المعلم
- اليوم
- توقيت البداية والنهاية

### 7. تسجيل التقدم اليومي

هذه إحدى أهم الميزات الخاصة بالمعلمين:

- اختيار الطالب
- تسجيل الحضور أو الغياب أو التأخر
- تحديد مستوى التفاعل
- تسجيل是否 تم تسليم الواجب المنزلي
- إدخال الدرجة والتعليق
- حفظ السجل اليومي أو تحديثه لاحقاً

### 8. التقارير الأسبوعية

يمكن للمشرف توليد تقارير أسبوعية للطلاب بصيغة PDF وتضم:

- تقدم الطالب خلال الأسبوع
- الواجبات المخصصة له
- المعلومات الدراسية المرتبطة بالطالب

### 9. الإشعارات الداخلية

النظام يدعم إشعارات داخلية عند:

- توليد تقرير أسبوعي جديد
- إكمال جميع سجلات التقدم الخاصة بمعلم معين

## الأدوار والوظائف حسب المستخدم

### المشرف (Admin)

الوظائف المتاحة له:

- لوحة تحكم إحصائية
- إدارة الطلاب
- إدارة المعلمين
- إدارة المواد
- إدارة المستويات
- إدارة التعيينات بين المعلمين والطلاب
- إدارة الجداول
- عرض جميع التقدم المدرّس
- إنشاء التقارير الأسبوعية
- إدارة الإشعارات

### المعلم (Teacher)

الوظائف المتاحة له:

- الدخول إلى لوحة التحكم الخاصة به
- عرض الطلاب المخصصين له
- تسجيل التقدم اليومي للطلاب
- مراجعة تاريخ سجلات التقدم
- الاطلاع على الإشعارات

### الطالب (Student)

الوظائف المتاحة له:

- عرض لوحة الأداء الخاصة به
- الاطلاع على الأداء العام
- عرض الجدول الدراسي
- تحميل التقارير الخاصة به
- الاطلاع على الإشعارات

## البنية الأساسية للمشروع

```text
app/
  Http/Controllers/       # Controllers الخاصة بالمسارات
  Http/Middleware/        # الوسيطات
  Livewire/               # مكوّنات Livewire مثل تسجيل التقدم
  Models/                 # نماذج قاعدة البيانات
  Notifications/          # إشعارات النظام
  Policies/               # سياسات الوصول
routes/web.php            # تعريف المسارات الرئيسية
resources/views/         # ملفات Blade والواجهات
database/migrations/     # هياكل الجداول
public/                  # الملفات العامة مثل الصور
```

## أهم المجلدات والملفات

- app/Http/Controllers: يحتوي على منطق الصفحات لكل دور
- app/Models: يحتوي على نماذج مثل Student و Teacher و DailyProgress و WeeklyReport
- app/Livewire/Teacher: يحتوي على مكوّن Livewire المستخدم في تسجيل التقدم اليومي
- routes/web.php: يعرّف المسارات الخاصة بالإدارات المختلفة
- resources/views: يحتوي على الواجهات الخاصة بالمدير والمعلم والطالب
- database/migrations: يحتوي على ملفات إنشاء الجداول

## تثبيت المشروع

1. انسخ ملف البيئة:

```bash
cp .env.example .env
```

2. ثبّت الحزم PHP والـ Frontend:

```bash
composer install
npm install
```

3. أنشئ مفتاح التطبيق:

```bash
php artisan key:generate
```

4. عدّل بيانات قاعدة البيانات في ملف .env حسب بيئتك.

5. شغّل الترحيلات:

```bash
php artisan migrate
```

6. إذا كانت هناك Seeders جاهزة، شغّلها:

```bash
php artisan db:seed
```

7. أنشئ ملفات الواجهة الأمامية:

```bash
npm run build
```
